# TLS Certificate Validator

## Overview
This application is designed to securely fetch and verify TLS certificates. It ensures robust security by initiating communication with a TLS client "hello" message, followed by certificate retrieval.

**Note:** This application is still under development.

## Features
- **Construct TLS Client Hello Message:** Initiates a secure session by sending a TLS client "hello" message.
- **Fetch and Decrypt Certificates:** Retrieves and decrypts TLS certificates from the server.
- **Certificate Validation:** Performs thorough checks on the certificates to verify their authenticity and integrity.
